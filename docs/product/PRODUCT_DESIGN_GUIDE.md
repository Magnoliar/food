# 产品与设计指导

更新时间：2026-06-09

配套执行清单见：[真实使用复盘](./PRODUCT_REAL_USE_REVIEW.md)。

## 产品气质

猪猪家的厨房应该像一个家里常用的小本子和厨房台面。它要可靠、安静、有一点温柔，能在晚饭前帮忙少纠结一点，在做完饭后帮忙把真实反馈留下来。

所有页面和动效都围绕一个问题取舍：

```text
今晚吃什么，怎么准备，怎么做，做完留下什么？
```

## 功能分层

主流程：
- 首页：今天要做什么。
- 计划：这一周怎么吃，顺手看购物清单。
- 做饭：照着步骤做完。
- 记录：做完留下照片、评分和备注。

辅助探索：
- 菜谱：找菜、改菜、新增菜。
- 食材：看库存、替代品和能做什么。
- 图谱：发现菜和食材的关系。

回顾与情绪价值：
- 旅程：回看这段时间吃过什么。
- 成就：轻轻鼓励记录和尝新。
- 海报：把一次好看的饭留下来。

维护层：
- 管理：配置、健康检查、导入和维护。只对 admin 可见。

## 页面判断

首页：
- 保留：今日菜、开始做饭、未规划提醒、待记录提示。
- 调整：首屏 5 秒内回答“今天吃什么”和“下一步做什么”。
- 避免：Demo、测试按钮、开发备注、过多统计卡片、静态周计划污染当前周。

计划：
- 保留：一周视图、保存计划、生成购物清单、智能填充。
- 新增：左右箭头切换上/下周，过去周显示"已过去"标识但仍可编辑；每天可标记"不安排"（虚线卡片 + 原因）。
- 调整：移动端保留轻量小卡片气质，不允许横向溢出、日期夹在餐位之间或右侧大块留白。
- 避免：把太多探索信息塞进计划页，也避免解释性备注占据首屏。

菜谱：
- 保留：搜索、筛选、随机一道、新建和编辑。
- 调整：搜索和新增优先于统计展示。
- 避免：统计信息压过找菜和做菜入口。

做饭模式：
- 保留：全屏步骤、进度、倒计时、完成后记录。
- 调整：手机上字号更大，按钮更好点；同一设备离开后回来应恢复当前步骤和随手备注。
- 避免：大幅动画、旋转、弹跳和遮挡步骤的装饰。

购物清单：
- 保留：勾选、家里已有、手动添加、刷新不丢。
- 调整：作为计划页的一部分展示；移动端优先未完成项，分类可折叠；”家里有”应算作已处理；已标记”不安排”的天不产生购物项。
- 避免：重新生成后丢失勾选状态。

记录、旅程、成就：
- 记录是事实，旅程是复盘，成就是轻激励。
- 三者要分清，不要把记录页做成任务榜。

海报：
- 优先使用菜品实拍作为主体。
- 食材可以放在下方一圈圆形卡牌里作为辅助。
- 不要用食材图替代菜品封面。
- 模板切换保留卡片左右箭头、移动滑动和下方点点，避免同时出现多套文字按钮。
- 缺照片、评分、食材或步骤时，编辑入口放在海报外侧，导出的图片里只保留卡片本身。

## 真实使用痛点复盘

晚饭前：
- 首页要让人快速知道今天吃什么、下一步做什么、还有没有缺口。
- 计划页要像排家里的饭，不像填后台表格；AI 补空位应该尊重已经手填的想法。

买菜时：
- 购物清单和库存状态是移动端高频信息，不能藏在太深的位置。
- 勾选、家里已有、重新生成都要稳定保存，不能让人在超市里重新确认一遍。

做饭中：
- 做饭模式要大字、少干扰、按钮好点，适合手上有水或隔着台面看。
- 步骤、倒计时、完成记录的反馈要明确，避免页面跳动和复杂控件。

做完后：
- 记录要轻，照片、评分、复盘能快速补；打卡页发现缺信息时能直接回到对应编辑位置。
- 打卡是留念，不是运营工具；前端文字要像家里说话，不要像产品后台。

长期使用：
- 旧测试数据、开发说明、重复入口、空状态冷冰冰，都会让应用不像日常会用的东西。
- 增强功能要安静地服务主流程，不要挤掉计划、购物、做饭、记录这些高频任务。

## 文案原则

- 面向用户的页面不出现账号配置、环境变量、部署提示等开发说明。
- 少说“系统、平台、操作系统、正式态”等硬词。
- 文案尽量短，给动作和状态，不解释功能价值。
- 错误提示要告诉用户下一步能做什么。
- 维护文档可以写安全要求，但用户页面不展示部署说明。

## 动画原则

保留：
- 150-300ms 淡入。
- hover 反馈。
- 进度条变化。
- 抽屉滑入。
- 上传、保存、生成、勾选后的即时反馈。

避免：
- 页面大幅位移。
- 连续弹跳。
- 大面积旋转。
- hover 后按钮位置或尺寸变化。
- 卡片状态变化导致布局跳动。

移动端优先性能和可读性，减少玻璃模糊、大阴影和装饰性动画。

## 美学原则

- 保持 8px 左右圆角、纸感背景和暖色主按钮。
- 控制棕橙、米色和暖灰占比，加入绿色、番茄红、墨黑作为功能色。
- 真实照片用于菜谱封面、做饭记录和海报。
- 线稿用于食材、空状态和图谱节点。
- 标题可以保留 serif 气质，操作密集区域以 sans 为主。
- 页面要像家里真实会用的东西，不像展会大屏。

## 成品验收

- 首页首屏能快速回答“今天吃什么、下一步做什么”。
- 首页使用真实当前周和真实购物清单，不再用静态示例数据判断日常状态。
- 未登录不会闪现业务内容。
- 移动端底栏固定为：首页、计划、菜谱、食材、打卡。
- 计划页移动端不能横向溢出。
- 所有保存、上传、生成、勾选都有状态反馈。
- 做饭模式在手机上无需放大即可阅读。
- 做饭模式离开后回来不丢步骤，完成后能直接补照片、评分和复盘。
- 图片和装饰不遮挡关键信息。
- 文案不把开发配置暴露给普通使用者。
