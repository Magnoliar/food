### **💡 备菜小贴士 (Tips)**

1. **周二干锅高效法：** 排骨比较难熟，建议先用高压锅压10分钟或者提前煮熟，再和鸡翅、土豆一起下锅干煸，这样口感更酥脆。
2. **虾汤浓郁秘诀：** 虾头不要扔！先用油煸炒虾头挤出“虾油”，再加入番茄炒出汁，最后加水煮汤，汤头会呈现诱人的金红色。
3. **咖喱鸡留餐：** 咖喱类菜品隔夜后味道会更融合，非常适合做第二天的便当。
4. **红油兔丁：** 兔肉煮熟后捞出过凉水，肉质会更紧实。拌入红油后静置半小时更入味。
5. **叻沙米线：** 盒马有现成的叻沙酱包，加入椰浆是灵魂，可以让汤底瞬间变得地道浓郁。
