# ✅茄汁辣酱八爪鱼意面
## 🥢食用方法：
* 第二天要吃的时候，记得头天回家以后提前把意面酱从冷冻拿到冷藏解冻哦
* 用老锅装大半锅水，然后往里面抖一些的盐，让水咸咸的，然后再往里面倒一些橄榄油，烧开
* 从意面袋子里面先取出拇指和食指一握👌🏼的意面，再取出一半放进锅里，倒计时11分钟开始
* 开始烧水后，把意面料放在不粘锅里小火加热，若意面煮好前，意面料已经烧开了，可以先关火
* 倒计时完成后，用夹子将煮好的意面转移到意面料里，一边搅拌一边加热，等酱料均匀地裹满面条后，就把它们放到盘子里面开始享用吧🐽！
