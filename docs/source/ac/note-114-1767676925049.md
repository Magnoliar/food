## 盒马采买待办清单（按区域）

> 默认按“家里常备调味（盐、油、生抽老抽、料酒、醋、糖、淀粉）基本都有”来列；你如果缺哪样我再补全到清单。

### 【海鲜水产】
- [ ] 鲈鱼/适合烤的整鱼（1条，约700g-1kg）
- [ ] 扇贝肉（300-400g）

### 【肉禽蛋品】
- [ ] 排骨（400-600g，周二午餐用）
- [ ] 猪肉末/绞肉（300g，青椒酿肉用）
- [ ] 鸡（整鸡1只或鸡块约1-1.2kg，五香烧鸡）
- [ ] 鸡腿（4-6只，豉油鸡腿）
- [ ] 鸡蛋（10枚左右，炒饭用；若家里有可不买）
- [ ] 火锅用鸡肉：鸡腿肉/鸡块（600-800g，椰子鸡火锅；若周四买整鸡并能留出部分，也可不额外买）

### 【蔬菜菌菇】
- [ ] 莲藕（1-2节）
- [ ] 蒜苔（1把）
- [ ] 青椒/尖椒（6-8个，酿肉用）
- [ ] 木瓜（1个）
- [ ] 椰子鸡火锅配菜：金针菇/香菇、娃娃菜/生菜、冬瓜等（按喜好选2-3样）
- [ ] 香菜/小葱（可选，火锅/烤鱼点缀）
- [ ] 生姜、大蒜（如家里不够再买）

### 【水果/乳品/甜品】
- [ ] 椰奶（1-2罐/盒，木瓜椰奶西米露）
- [ ] 西米（1包）
- [ ] 炼乳/淡奶油（可选，想更香甜再买）

### 【主食/面点】
- [ ] 米（或隔夜米饭用量不够则补）
- [ ] 椰子鸡火锅蘸料/配主食：粉丝/河粉/乌冬（可选其一）

### 【调味/干货】
- [ ] 烤鱼用：麻辣调料/干辣椒、花椒（缺再买）
- [ ] 糖醋汁关键：白糖/冰糖、米醋/陈醋、番茄酱（缺再买）
- [ ] 五香烧鸡：五香粉/卤料包、老抽（缺再买）
- [ ] 豉油鸡腿：生抽、老抽、冰糖（缺再买）
- [ ] 椰子鸡：椰青（2-3个）或椰子水（1-2瓶）、枸杞/红枣（可选）
