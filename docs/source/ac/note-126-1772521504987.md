### **💡 厨事小贴士**

1. **高效备餐 (周四/周六)：** 土豆烧排骨和番茄牛腩都是“越炖越入味”的菜，非常适合第二天带饭。建议在做晚餐时多留出一份，直接装入便当盒密封冷藏。
2. **冬去春来饭：** 这是一个懒人焖饭。将香菇、笋丁、腊肠先下锅炒香，加入生抽、老抽调味，然后和洗好的米一起放入电饭煲，按常规煮饭键即可。
3. **回锅肉技巧：** 五花肉记得先冷水下锅，加姜片料酒煮至 8 分熟（筷子能扎透），捞出晾凉切薄片再炒，这样口感才肥而不腻，灯盏窝明显。
4. **四季豆预警：** 四季豆炒肉末做包子馅时，**四季豆一定要先焯水煮熟或充分炒熟**，避免中毒。
