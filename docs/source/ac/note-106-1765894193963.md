如果是小白，建议从最简单粗暴的定压定频入手，防掉压开到LV6（没记错的话ASUS这个选项应该是基本不掉压），然后定频P5.5 E4.3 Ring4.5，cpu核心电压不要用offset，用manual，从1.28V开始尝试（参考：我sp99的139K 在msi上是可以1.20V稳定5.5G的，考虑到这个电压可能偏低，加到1.22V为基准，华硕socket电压比微星vcc大概高0.06，那么就从1.28开始试），跑R23 10圈观察功耗和温度；如果弹窗，就往上加，直到稳定。最后通过测试的电压，再加0.01-0.02日用，就没啥大问题了。希望能赚到邪恶~

另外CPU温度以CPU Package为准。
