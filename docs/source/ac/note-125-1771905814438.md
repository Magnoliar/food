### **💡 给 momo 的备菜小贴士：**

1. **分量控制：** 既然是3人晚餐+2人午餐，周三的**豉油鸡**和周四的**炒肉/鱼块**建议直接做平时1.5倍的分量。
2. **周二的米线：** 晚餐吃米线，但午餐带米线容易坨。所以周二晚上多煮一锅米饭，午餐用**干煎鸭**配米饭和补一个**清炒时蔬**。
3. **周五的意面：** 虾滑和羊肚菌非常鲜。如果周六中午不想吃意面，可以周五晚上多留一点虾滑，周六中午做个**虾滑蛋炒饭**，非常快手。
4. **周六的海鲜鲍鱼鸡：** 这是一个大菜，汤底非常鲜美。周日中午直接煮个面条投进汤里，就是超豪华的**海鲜鸡汤面**。
5. **周日的包子：** 既然妹妹在，可以一起动手包包子，增加互动乐趣。多包一些，周一的早午餐都解决了。
