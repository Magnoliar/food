![Image 15](https://i-operation.csdnimg.cn/images/a7311a21245d4888a669ca3155f1f4e5.png)文章介绍了如何在无需更换硬件和降低CPU性能的情况下，通过调整I913900K的电压和电源管理设置，将CPU电压从1.43V降低到1.275V，成功将待机温度从50多度降至30多度，显著降低了功耗和温度问题。 

I9 13900K 默认情况下，电压很大，待机电压1.43v，功耗特别大，程序运行一段时间 cpu 温度高达100度，甚至死机。 在不更换现有硬件以及降低cpu性能的条件下，通过下操作可以大幅度降低cpu温度

 改变前如下图

1.   ![Image 16: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/0bc9ced8233890b04a75e4781b0f2df0.jpeg)

 设置步骤：

 1.在DIG+VRM中将cpu load-line cablibration 级别由默认的level-3 调整到 level-6

![Image 17: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/4e99a0f2581902d74733a12556ae6d66.jpeg)
2.   在Internal cpu power management 中将IA AC load line参数由原来的auto 修改成 0.13

![Image 18: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/58b5d1d7be4c108c893469d790f1bbec.jpeg)

![Image 19: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/52e5ef762756e1b256b9bc39fe19907b.jpeg)

 3 将Actual VRM core voltage 参数由原来的auto 改成offset mode，offset mode sign 改成 **“-”**，cpu core voltage offset 参数修改成 0.06

![Image 20: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/30964422dfdb99cbd7276e96732c6afe.jpeg)

 3. 保存退出

 4. cpu电压由原来的1.43 变成了1.27

 5.![Image 21: 在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/4222a136c5a814e41f2856fff0dead7d.jpeg)
