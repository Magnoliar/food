### **采买清单 (建议一次性或分两次购齐)**

#### **1. 水产海鲜 (建议当天或提前一天购买)**

* [ ] **罗氏虾** (500g-750g)：选个头大、活泼的。
* [ ] **小龙虾** (2-3斤)：若买活虾需预留刷洗时间，也可买盒马半成品加热。

#### **2. 肉禽蛋品**

* [ ] **猪蹄** (1-2只)：请摊主剁成小块，方便烹饪和装便当。
* [ ] **猪肉** (300g)：五花肉或前腿肉，用于油豆腐炒肉。
* [ ] **盐水鸭** (半只/一只)：推荐买现成的熟食。
* [ ] **鸡蛋** (1盒)：用于炒饭、蒸蛋、螺蛳粉加餐。
* [x] **火腿/午餐肉** (1份)：用于周三的炒饭。

#### **3. 蔬菜菌菇**

* [ ] **油豆腐** (1袋)：约200g。
* [ ] **青椒/螺丝椒** (3-4个)：用于炒肉。
* [ ] **黄瓜** (2根)：用于拍黄瓜和炒饭。
* [ ] **时令青菜** (2-3把)：如上海青、菜心，用于周二、周五晚餐及螺蛳粉配菜。
* [ ] **胡萝卜** (1根)：用于炒饭配色。
* [ ] **柠檬/青柠** (1-2个)：用于芥末罗氏虾调味。
* [ ] **葱姜蒜、小米辣** (必备)：消耗量较大，建议备足。

#### **4. 主食与调料**

* [ ] **螺蛳粉** (1-2包)：袋装速食。
* [ ] **芥末酱/青芥膏** (1支)：用于罗氏虾。
* [ ] **酸辣猪蹄调料**：白醋、泡椒、白糖、生抽（或直接买酸辣汁）。
* [ ] **小龙虾调料**：若买活虾，需买专门的小龙虾底料。

### **烹饪小贴士**

1. **周二（炒饭准备）：** 晚餐煮饭时，水量比平时稍微少一点点，煮出来的米饭粒粒分明。盛出一大碗晾凉后放进冰箱冷藏，第二天炒饭才好用。
2. **周三（酸辣猪蹄）：** 猪蹄建议用高压锅压20-25分钟，再放入酸辣汁中浸泡。这道菜冷吃热吃均可，带便当非常方便。
3. **周四（油豆腐炒肉）：** 油豆腐可以对半切开，这样更容易吸收肉汤的鲜味。
4. **周六（小龙虾）：** 如果觉得洗虾麻烦，盒马的“神丹”系列或冷冻调味小龙虾也是不错的选择，加点黄瓜或土豆片进去煮，味道更丰富。
5. **周日（螺蛳粉升级）：** 煮螺蛳粉时，把周五周六剩下的青菜、剩下的几个罗氏虾或者煎个蛋丢进去，就是豪华版螺蛳粉。

祝您本周用餐愉快！
