# 【低温慢煮复刻版 · 少油贵州辣子鸡】完整教程 (800g鸡腿肉)

**核心理念**：利用现代烹饪科学，精准复现传统风味，健康与美味兼得。

**【主要食材】**

* 鸡腿肉（带皮去骨）：800克，斩成约3-4厘米的块。

**【第一阶段：盐水腌制】**

* 饮用水：1000毫升 (1升)
* 食盐：40克

**【第二阶段：准备糍粑辣椒】**

* 干辣椒（如灯笼椒、二荆条等，取其香）：60克
* 生姜：40克，切片
* 大蒜：40克，去皮

**【第三阶段：最终炒制与调味】**

* 菜籽油（或其他植物油）：2-3汤匙 (约30-45毫升)
* 酱油（或生抽）：1汤匙 (15毫升)
* 白糖：1茶匙 (约5克，用于提鲜和平衡味道)
* 花椒粉：1茶-1.5茶匙 (约5-8克，根据喜好调整)
* 鸡精或味精（可选）：1/2茶匙 (约2-3克)
* 盐：适量（最后根据味道调整）

**【所需设备】**

* 带“保温”功能的电饭煲
* 耐高温食品级密封袋（或真空袋）
* 炒锅
* 厨房纸巾

---

### 【制作步骤】

**第一步：盐水腌制（耗时4小时，关键增嫩步骤）**

1. 在容器中将1000毫升水和40克盐搅拌至完全溶解，制成4%的盐水。
2. 将切好的800克鸡腿块放入盐水中，确保完全浸没。
3. 容器封上保鲜膜，放入冰箱冷藏浸泡4小时。

**第二步：准备糍粑辣椒（可在腌制鸡肉时进行）**

1. 干辣椒用温水泡软（约30分钟），捞出沥干水分。
2. 将泡软的辣椒、姜片、蒜瓣一同放入料理机或臼中，打/捣成粗糙的泥状，糍粑辣椒即成。

**第三步：低温慢煮（耗时2-2.5小时，核心熟化步骤）**

1. 将盐水浸泡好的鸡块捞出，用流动的清水**彻底冲洗干净**表面的盐分。
2. 取出后，用足量的厨房纸巾**将每一块鸡块的里外都彻底、完全地擦干**。这一步至关重要，直接影响后续的焦香效果。
3. 将擦干的鸡块分装入耐高温密封袋中，用“水中排气法”或真空机尽量排出空气并封口。
4. 在电饭煲内注入足量热水，放入鸡肉袋，按下\*\*“保温”\*\*键。慢煮2至2.5小时。

**第四步：最终炒制（耗时5-8分钟，灵魂赋味步骤）**

1. 鸡肉慢煮完成后，从袋中取出，再次用厨房纸巾**轻轻吸干表面的汁水**。
2. 中大火预热炒锅，锅热后，倒入2-3汤匙油。
3. 油温五成热时，转中小火，下入准备好的糍粑辣椒，耐心煸炒约3-5分钟，直至辣椒的香气完全释放，油色变得红亮。
4. 转**大火**，将擦干的鸡块下入锅中，快速翻炒约1-2分钟。目的是让鸡皮的各个面都能接触到灼热的锅壁，产生轻微的焦香感。
5. 沿锅边淋入1汤匙酱油，快速炒匀。
6. 加入1茶匙白糖，继续翻炒均匀。
7. 此时尝一下酱汁的味道，因为鸡肉已有底味，所以根据您的口味**酌情加入最终的盐**。
8. 关火前，撒入花椒粉和鸡精（如果使用），快速颠勺几下，即可出锅。

这样，一盘用油量极少，但风味、口感却高度还原传统的贵州辣子鸡就完成了。尽情享用吧！
