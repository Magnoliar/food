---

**💡 备菜小贴士：**

1. **周二披萨：** 如果做梅干菜披萨，建议先将梅干菜和五花肉末炒香（加少许糖和生抽），再铺在饼底上撒芝士，味道更浓郁。
2. **周四豉油鸡腿：** 可以在周三晚上煮好，在卤汁里浸泡过夜，周四早上装盒，味道最入味。
3. **周五爱马仕炒饭：** 核心是“配料丰富”，可以把冰箱里剩下的和牛、虾仁、香菇丁、甚至一点点松露酱都放进去，米饭一定要用隔夜的。
4. **周六乌鸡：** 乌鸡干煎前建议先用姜片、料酒和少许盐腌制20分钟，煎至皮焦黄时放入香菇，香菇吸收鸡油后非常鲜美。
5. **周日包子：** 既然要做包子，可以多做一些冷冻起来，作为下周的应急早餐。
