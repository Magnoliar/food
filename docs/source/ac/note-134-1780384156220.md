### **💡 厨艺小贴士：**

1. **凉拌鲫鱼 (周二)：** 鲫鱼刺多，煮熟后捞出，淋上由大量**小米辣、蒜末、香菜、生抽、醋、糖和藿香（如果有）**调制的料汁。这道菜的关键是料汁要重，鱼肉要鲜。
2. **孜然糊辣牛肉 (周三)：** 牛肉切薄片后先用生抽、淀粉、油抓匀腌制。炒的时候先炸香干辣椒和花椒（炸到微糊变色，即“糊辣”），再下牛肉大火快炒，最后撒入大量孜然。
3. **油豆腐烧肉 (周四)：** 油豆腐非常吸汁，建议五花肉多炖一会儿出油，再放油豆腐，这样油豆腐会比肉还好吃。
4. **周日备餐：** 番茄牛腩炖一大锅，周日晚上吃一顿，剩下的汤汁和牛腩周一中午带便当，拌在米饭里简直是办公室最香的午餐。
