# **改良版万能牛肉辣椒酱**

配料调整：

- 替换： 冻虾仁（替代海米/虾皮200g）、坚果碎（替代花生碎160g）
- 新增： 牛肉末（建议选用带点肥油的部位，更香100g）
- 保留： 食用油 1000g、葱 130g、姜 15g、蒜 210g、大料 2个、花椒 10粒、白芝麻 150g、辣椒碎 200g、豆瓣酱 170g、味精 2g

制作步骤优化：

1. 食材处理：

   - 冻虾解冻后尽量挤干水分，切碎。
   - 坚果切碎。
   - 牛肉切成肉末。
   - 蒜切片或末（按原教程需泡水去苦味），葱姜切好备用。
2. 炒干水分（关键步骤）：

   - 因为用了冻虾和鲜牛肉，水分比干货多。建议先起锅烧少量油，分别将牛肉末炒至变色、水分收干、吐油，盛出备用；再将虾碎也炒至金黄干香，盛出备用。这一步能防止辣酱变质。
3. 炸香料油：

   - 锅中倒入主量的食用油，下葱、姜、花椒、大料，炸至金黄焦香后捞出残渣（葱姜可留做他用）。
4. 炸蒜与熬酱：

   - 放入蒜片/蒜末，小火浸炸至金黄。
   - 加入豆瓣酱，炒出红油。
5. 混合熬制：

   - 加入辣椒碎、提前炒干的牛肉末和虾碎、坚果碎、白芝麻。
   - 小火熬煮几分钟，让香味融合，注意搅拌防糊底。
6. 调味出锅：

   - 最后加入味精，搅拌均匀即可关火。晾凉后装瓶密封。
