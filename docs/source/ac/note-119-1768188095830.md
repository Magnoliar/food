# 家庭披萨制作指南

---

### 第一部分：万能披萨面团配方（两人份，做两张）

不用复杂的酵母种，这个配方专为家庭烤箱设计，**油和糖略多**，为了保证在230度下也能酥脆上色。

* **高筋面粉（或普通中筋面粉）：** 250克
* **温水（约35度）：** 160克（水量适中，稍微粘手是正常的）
* **酵母（干酵母）：** 3克（约小半勺）
* **盐：** 3克
* **细砂糖（关键）：** 10克（帮助上色）
* **橄榄油（或玉米油）：** 15克（约一汤匙）

**馅料准备（越少越好）：**

* **必选：** 马苏里拉芝士碎（150克左右）、披萨酱（或者番茄酱+披萨草/黑胡椒）。
* **可选（切薄/炒熟）：** 萨拉米香肠、培根（煎熟）、洋葱丝、口蘑片（建议干炒一下去水）。

---

### 第二部分：详细操作步骤

#### 1. 揉面与发酵（提前1-2小时）

1. **混合：** 把水、酵母、糖混合化开。倒入面粉、盐、油。
2. **揉成团：** 用筷子搅成絮状，上手揉成一个光滑的面团（不需要揉出手套膜，表面光滑即可，大概揉5-8分钟）。
3. **发酵：**
   * **快手版：** 盖上湿布或保鲜膜，放在温暖处发酵 40-60 分钟，直到面团变大两倍。
   * **好吃版（推荐）：** 提前一晚揉好，扔进冰箱冷藏发酵一晚，第二天拿出来回温半小时再用，风味更好。

#### 2. 整形（关键：配合硅油纸）

1. **分剂子：** 发好的面团排气，**一分为二**，滚圆，盖保鲜膜松弛15分钟（松弛后的面才好擀，不会回缩）。
2. **铺纸：** 撕两张**硅油纸**（烘焙纸），大小要能放进你的烤箱。
3. **擀开：** 把面团直接放在**硅油纸上**擀开/推开。
   * *注意：* 你的锅是牛排锅，如果是方形的，就把面饼擀成**方形**；如果是圆的就擀圆。**饼的大小一定要比你的锅底略小一点**，否则边缘会塌下去。
4. **扎孔：** 用叉子在饼底戳很多小洞（防止烤的时候鼓大包），边缘留1厘米不要戳（做饼边）。
5. **放料：** 涂酱 -> 撒一层薄芝士 -> 铺肉和菜 -> 撒厚芝士覆盖。

#### 3. “冰火两重天”烘烤大法

**请务必注意安全，此时锅底温度极高！**

1. **烤箱预热：** 开启烤箱最高温 **230°C**，不用放烤盘，只放烤网（架子），位置放在**中层**。
2. **燃气热锅（最关键的一步）：**
   * 把铸铁牛排锅**倒扣**在燃气灶上（锅底朝上，平的那面朝上）。
   * 开**中大火**烧 **5-6分钟**。此时锅底温度会非常高。
3. **转移锅（高危动作）：**
   * **关火**。
   * 戴上**厚棉手套**（千万别用湿布），双手抓稳锅把手，迅速把滚烫的锅放进烤箱的烤网上（依然是**倒扣**状态）。
   * 关上烤箱门让温度均匀一下（约30秒）。
4. **入炉烘烤：**
   * 把放在硅油纸上的披萨，连纸一起放在一块硬纸板、砧板或平盘上（充当披萨铲）。
   * 拉开烤箱门，把披萨**连着纸**滑到那个滚烫的铸铁锅底上。
5. **计时：**
   * 关门烤 **6-9 分钟**。
   * 最后2分钟盯着看，芝士融化起焦斑，饼边金黄即可出炉。

---

### 第三部分：避坑指南

1. **关于牛排锅的条纹：**
   * 因为我们是**倒扣**用锅底，所以锅里的条纹不会影响披萨。
   * 万一觉得倒扣太危险，不敢操作，那就把锅正过来（条纹面朝上），烧热后把披萨放进去。虽然底部会有条纹印，不太好铲，但也能熟。如果是这种情况，记得把面饼擀得稍微厚一点点。
2. **关于出水：**
   * 你的烤箱只有230度，千万**不要放生番茄、生青椒、生菠萝**这种水分大的东西。如果要放，一定要先用平底锅炒干，或者用厨房纸吸干水分。
3. **第一张和第二张的衔接：**
   * 烤完第一张后，你的铸铁锅温度会下降。
   * 如果想烤第二张同样酥脆，建议把锅拿出来，重新在燃气灶上**中火加热2-3分钟**补一下热量，然后再进烤箱烤第二张。
