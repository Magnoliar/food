### 1）麻辣糖醋烤鱼（1餐）
**关键词**：麻辣 + 糖醋（酸甜）+ 烤/焗

**食材（按实际补充）**
- 整鱼 1 条（鲈鱼/清江鱼等）
- 葱姜蒜
- 干辣椒/花椒
- 生抽、老抽（可选上色）、料酒
- 白糖/冰糖、醋（米醋/陈醋）、番茄酱（可选）
- 盐、胡椒、食用油

**做法（简版记录）**
1. 鱼处理干净擦干：用盐+料酒+姜葱腌 10–20 分钟。
2. 调糖醋麻辣汁：生抽 + 醋 + 糖（可加少量番茄酱），另起锅爆香蒜姜、干辣椒、花椒后倒入调好的糖醋汁，小火熬到略浓。
3. 鱼表面刷油（或垫蔬菜/洋葱增香），烤/焗到熟（中途刷汁 1–2 次）。
4. 出炉再淋一遍热汁，撒葱花。

### 2）麻辣糖醋烤鱼汁烧莲藕排骨（1餐/便当）
**思路**：用烤鱼剩余的麻辣糖醋汁做“二次利用”，烧排骨+莲藕。

**食材**
- 排骨（焯水）
- 莲藕（切块/片）
- 复用：麻辣糖醋烤鱼汁（剩余）
- 清水/高汤
- 葱姜蒜（可选）

**做法（简版记录）**
1. 排骨冷水下锅焯水，洗净。
2. 锅中少油爆香葱姜蒜（可选），下排骨翻炒。
3. 加入烤鱼剩余麻辣糖醋汁，补少量水/高汤没过食材。
4. 小火炖 20–40 分钟至排骨软烂；中途加入莲藕继续炖到透。
5. 大火收汁，尝味后补盐/糖/醋（按需要）。
